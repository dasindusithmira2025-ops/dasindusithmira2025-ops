## Building the layer after the IDE

Most developer tools still assume the human writes the code.

I’m building for the point where humans define intent, agents perform the work, and the environment coordinates everything between them.

My current obsession is **Paralith** — an agentic development environment for managing AI agents, repositories, terminals, worktrees, memory, verification, and delivery inside one coherent system.

```text
intent
  └─ mission
      ├─ planner
      ├─ builders
      ├─ reviewers
      └─ evidence
           └─ shipped software
```

Not another editor with a chatbot bolted onto the side.

A control system for software creation.
