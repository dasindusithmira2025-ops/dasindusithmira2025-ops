### Featured

**[PulseBoost](https://github.com/dasindusithmira2025-ops/pulseboost_cpp)** — a Windows gaming and
PC optimization desktop application built around transparency and reversibility. It monitors live
CPU, GPU, RAM, and network signals, applies only optimizations it can safely roll back, and records
every system action in an audit trail with plain-English rationale. Unsupported capabilities are
surfaced honestly in the app rather than quietly faked.
